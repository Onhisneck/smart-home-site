# Данные проекта: сайт компании по монтажу систем «Умный дом»

Проект: веб-сайт компании по проектированию и монтажу систем «Умный дом» с модулем приёма заявок
(Python + FastAPI, SQLite, уведомления через Telegram Bot API).

Автор: Паёлов Р. Е., группа ИСИб-25-1, ИрНИТУ.

Данные ниже показывают актуальность проекта: рынок «умного дома» в России растёт, а потенциальные клиенты
готовы оставлять заявки онлайн и предпочитают связь через Telegram.

## Файлы

### `data/smart_home_market_russia.csv` — реальные данные из открытых источников

Показатели рынка «умного дома» в России за 2013–2025 годы. У каждой строки указаны источник и ссылка.

| Столбец | Описание |
|---|---|
| `indicator` | показатель |
| `year` | год |
| `value` | значение (диапазон записан через «–») |
| `unit` | единица измерения |
| `type` | факт / оценка / прогноз |
| `source` | кто опубликовал данные |
| `url` | ссылка на публикацию |

Главное:
- доля российских домохозяйств с технологиями «умного дома» выросла примерно с 4 % (2019) до 9 % (2024);
- продажи устройств оценивались в 1,2 млрд долл. с прогнозом 2,7 млрд долл. к 2025 году;
- в мире этот показатель 27–29 %, то есть у российского рынка большой запас роста.

Оценки разных аналитиков считаются по-разному (только устройства, или вместе с монтажом и услугами),
поэтому их нельзя напрямую сравнивать между собой.

### `data/potential_clients_survey_synthetic.csv` — синтетические данные

**Данные сгенерированы**, потому что открытых данных опросов
по нашему региону нет. Они моделируют опрос 400 потенциальных клиентов.

| Столбец | Описание |
|---|---|
| `respondent_id` | номер респондента |
| `age` | возраст |
| `housing_type` | тип жилья: квартира / частный дом / таунхаус |
| `area_m2` | площадь жилья, м² |
| `has_smart_devices` | уже есть устройства умного дома (Да/Нет) |
| `smart_devices_count` | сколько устройств |
| `interested_in_installation` | интерес к установке системы: Да / Скорее да / Скорее нет / Нет |
| `priority_function` | самая важная функция |
| `budget_rub` | готовый бюджет, руб. (0 — не заинтересован) |
| `preferred_contact` | предпочтительный способ связи |
| `ready_to_leave_online_request` | готов оставить заявку на сайте (Да/Нет) |

Что видно из данных:
- около 64 % респондентов ответили «Да» или «Скорее да» на вопрос об установке;
- около 60 % готовы оставить заявку на сайте, а это и есть основная функция проекта;
- Telegram — самый популярный способ связи (около половины ответов), поэтому заявки приходят через Telegram Bot API.
